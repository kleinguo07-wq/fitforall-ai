# 公园横屏公开原型

`v0.6/index.html` 是从当前本地评审原型生成的独立公开快照，不代表真实产品上线。样式、脚本和 SVG 均内嵌，无外部媒体依赖。课程与动作选择、站位、运动反馈、本站服务及首页推荐轮换保留；相机、评分、身份、媒体、小程序码与环境数据仍为模拟。

在仓库根目录执行：

```sh
python3 scripts/sync_landscape_prototype.py --source '/path/to/current-landscape-prototype.html'
```

脚本只更新固定的 `projects/landscape/v0.6/index.html` 和 `version.json`，不复制原始表格、PRD、研究或归档。同步时移除内部定位字段与研究链接，替换公开导航与说明；发现额外依赖、私人路径或缺失的关键行为标记会直接停止。`version.json` 仅记录版本、状态、入口及源文件 SHA-256，不记录源绝对路径。相同源文件重复同步产生相同输出。

公开导航约定：快照的“返回横屏项目”指向 `../`，“项目总览”指向 `../../../`；两页由项目入口构建流程提供。发布时必须连同项目入口检查这些相对链接，保留已有 FitForAll 页面，不将本目录当作整个站点覆盖发布。
