# 公园横屏公开原型

[项目背景与产品思考](https://kleinguo07-wq.github.io/fitforall-ai/projects/landscape/#background)位于横屏项目页，供项目组了解产品定位、四个方案亮点和三个持续思考。内容是设计希望兑现的价值与现场验证重点，不代表真实能力已交付。

`v1.0/index.html` 是从当前本地评审原型生成的独立公开快照，不代表真实产品上线。样式、脚本和 SVG 均内嵌，无外部媒体依赖。AI跟练、体能训练仅展示选择与详情，站位、运动中、结果及领取沿用原产品，不另画原型；设备外保留文字说明。趣味运动保留独立流程，运动视频保留观看演示；本站服务与首页推荐轮换保留。相机、评分、身份、媒体、小程序码与环境数据仍为模拟。

每页顶部均有“原型说明”按钮。开启后，编号标注对应当前画面功能，设备外说明面板列出用途、操作和规则；切换分类、页面或弹窗会同步更新。阅读时暂停首页推荐轮换、游戏和视频计时，关闭后从原进度继续。该功能只用于评审，不进入正式设备交互。

完整排行榜包含运动时长榜与卡路里消耗榜，默认显示本站今日运动时长，两个榜单独立排序、同值并列。卡路里为独立模拟的估算消耗，单位为千卡；正式计算口径与数据接入待核验。本站服务继续展示时长榜前8位预览。

在仓库根目录执行：

```sh
python3 scripts/sync_landscape_prototype.py --source '/path/to/current-landscape-prototype.html'
```

脚本只更新固定的 `projects/landscape/v1.0/index.html` 和 `version.json`，不复制原始表格、PRD、研究或归档。同步时移除内部定位字段与研究链接，替换公开导航与说明；发现额外依赖、私人路径或缺失的关键行为标记会直接停止。`version.json` 仅记录版本、状态、入口及源文件 SHA-256，不记录源绝对路径。相同源文件重复同步产生相同输出。

公开导航约定：快照的“返回横屏项目”指向 `../`，“项目总览”指向 `../../../`；两页由项目入口构建流程提供。发布时必须连同项目入口检查这些相对链接，保留已有 FitForAll 页面，不将本目录当作整个站点覆盖发布。

项目背景单独从本地需求数据的 `brief.product_background` 导出，修改后同步：

```sh
python3 scripts/sync_landscape_background.py --source '/path/to/需求内容.json'
python3 scripts/build_pages.py
```

导出文件 `background.json` 只含产品定位、亮点、思考和当前阶段说明，不复制内部需求、会议、研究或本地路径。背景更新不修改版本原型，发布后需核对项目页的 `#background` 链接。

## v1.0复用基线

2026-11-04用户确认当前方案与原型版本为v1.0。用户账号体系和横屏多人检测复用教学屏体验，共用过程不另行设计；社会体育账号跨横屏、竖屏、小程序通用，真实接入、人数及场地能力仍待联调验收。旧`v0.6/`公开快照冻结保留，新同步只更新`v1.0/`。

## v1.0管理后台评审

2026-11-06纳入本期：`v1.0/admin.html`是独立模拟页面，运动视频分AI全民健身机/AI全民运动站两个带图标Tab，公告设置固定仅支持运动站。真实后台源码未修改，原始参考HTML不发布。通过`python3 scripts/sync_landscape_admin.py --source /path/to/管理后台-评审原型-v1.0.html --requirements /path/to/管理后台需求-v1.0.md`导出；规则由本地需求JSON生成，当前屏端快照保持原内容。

2026-11-06项目页仅展示当前v1.0屏端和管理后台两个入口，采用同款卡片与“打开原型”按钮；后台需求保留为次级文字链接。不在项目页展示v0.6入口，历史公开快照仍保留。

本期埋点需求位于`v1.0/tracking.html`，含24组采集需求、复用映射、参数、去重和验收；`tracking.md`为同源文本，均为需求而非真实采集实现。项目页在v1.0版本区提供大屏端、后台和埋点三个同级入口。用`sync_landscape_tracking.py --source /path/to/埋点需求-v1.0.html --text /path/to/埋点需求-v1.0.md`同步，公开页不加载或发送生产埋点。

2026-11-06当前项目入口改为统一版本区：集中突出v1.0，在同一组内并列“大屏端原型”“管理后台原型”“埋点需求”三个整卡点击入口；仅展示当前版本，后台需求文本仍由原URL及版本元数据保留。
