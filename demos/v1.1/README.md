## 评审路径

1. 视频屏保：三类内容从开头最多播放 30 秒；短视频播完切换。右侧正圆按钮仅切下一项，支持双向横滑，底部首页占 1/3、一键跟练占 2/3，声音为静音／开启两态。
2. 一键跟练进入既有站位、身份与注册示意，自动开始后显示运动过程和普通报告。双人第二人注册与记录在 D03 用文字说明，不接真实识别或注册。
3. 人群内容使用原图；儿童“更多”进入趣味内容页并可返回，游戏本体不重复制作。
4. 屏保管理沿用现有后台；系统默认／自定义使用相同三类内容，自定义可勾选和排序，草稿保存后才生效。
5. D03、D04 从目录进入文字需求；心率入口控制在需求文档查看。

## 打开与边界

无需安装依赖。在仓库根目录运行 `python3 -m http.server 8765`，访问 `http://localhost:8765/demos/v1.1/`。埋点页需通过 HTTP 服务读取文档。

素材、身份、成绩与算法画面均为演示，不代表生产功能或素材已经交付。趣味运动视频需新制并本地打包；新增 3 个体能动作与易筋经需相应封面、视频、正式 ID 与识别配置。坐姿抬脚于 2026-10-27 实测效果不佳，本期不接入，清单保留删除线记录。默认图片为 assets/screensaver-fun-ai.jpg。

真实产品源码只读，本目录是独立需求演示。模拟数据使用当前版本独立本地存储；原有演示数据不删除。未接入真实接口、算法或生产发布。
