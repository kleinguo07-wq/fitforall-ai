# v1.1 交互评审 Demo

对应 [需求评审稿](../../docs/requirements/v1.1-product-review.md)。用于 UI 与研发走查，不是设备应用或正式发布版本。

## 打开

无需安装依赖。可直接打开本目录 `index.html`；推荐在仓库根目录执行：

```sh
python3 -m http.server 8765
```

浏览器访问 http://localhost:8765/demos/v1.1/ 。设备画布为 9:16，外侧工具用于模拟身份、加速时间与触发异常。

## 评审路径

1. 视频屏保：上一个／下一个、一键跟练、看看其他运动、图片模式互切。单项演示完整三遍；长课随机连续 30 秒。
2. 站位：模拟老用户确认、新用户注册、人脸失败后微信登录；开始后固定绑定本次身份。
3. 首页热身签到，或直接完成普通运动；查看单项体能、AI 跟练两种报告的统一进度卡。
4. 同一天多次运动、重放报告、换用户、模拟下一天，检查天数去重与个人累计。
5. 后台配置人群、指定内容池、顺序、长课区间、热身池及最多九张图片；保存后预览。
6. 模拟视频失败和空池，确认可返回首页或图片模式。

## 演示范围与待确认项

- 默认人物是动态 SVG 占位，不是实际运动视频。可在后台导入本地视频验证媒体轮播；长课区间需与导入视频长度匹配。
- 身份、人脸、微信、注册和运动成绩均为模拟；不请求摄像头、不调用登录服务。站位页的模拟确认按钮便于评审，生产自动身份确认沿用现有能力。
- 运动记录保存在当前浏览器 localStorage。配置、导入素材及新用户注册状态仅在当前页面会话有效；刷新会恢复默认配置。支持清除模拟数据。
- 提前退出按实际计时 **严格大于 10 秒** 演示；正常结束始终计入。这是待核实参数，不代表已经确定生产门槛。
- 里程碑档位、示例热身课程、首页／报告 60 秒待机均为评审假设；默认单人路径。
- 未实现真实算法、后台接口、生产素材发布、离线同步和多设备结算。演示图表、热量与评分不用于效果评价。
- 9:16 画布仅验证浏览器布局，43 寸设备触达、反光、音量与实际交互需现场复核。
