# v1.1 交互评审 Demo

对应 [需求评审稿](../../docs/requirements/v1.1-product-review.md)。用于 UI 与研发走查，不是设备应用或正式发布版本。

## 打开

无需安装依赖。可直接打开本目录 `index.html`；推荐在仓库根目录执行：

```sh
python3 -m http.server 8765
```

浏览器访问 http://localhost:8765/demos/v1.1/ 。设备画布为 9:16，外侧工具用于模拟身份、加速时间与触发异常。

## 评审路径

1. 视频屏保：素材复用对应运动详情页顶部视频，主要覆盖体能项目和 AI 跟练项目；历史 16:9 演示视频按 9:16 居中裁切铺满。支持上一个／下一个、左滑下一项／右滑上一项；底部左侧 1/3 为“首页”，右侧 2/3 为“一键跟练”，并支持当前视频静音／开启声音二态切换。单项演示完整三遍；长课随机连续 30 秒。屏保类型由客户后台单项选择，设备端不切换模式。
2. 站位：自动模拟老用户人脸确认、新用户注册、人脸失败后调整站位重试；开始后固定绑定本次身份。
3. 首页热身签到，或直接完成普通运动；查看单项体能、AI 跟练两种有效结果报告的统一进度卡；卡片显示今日已签到以及累计总天数、总消耗和总时长。
4. 同一天多次运动、重放报告、换用户、模拟下一天，检查天数去重与个人累计。
5. 客户后台选择目标人群及按人群智能推荐／指定内容池；指定内容池可调整顺序，保存后回到设备验证。
6. 模拟视频失败和空池，确认可重试或返回首页。

设备体验页的设备旁提供“查看本页需求”，点击后直接在设备画布中展示当前页面相关的 3～4 条精简需求。切换屏保、首页、站位、运动、报告或我的数据时，备注同步更新；再次点击、关闭按钮或按 Escape 收起。

## 演示边界与待确认项

- 默认使用不同配色的静态色块占位，不是实际运动视频。正式视频复用对应运动详情页顶部视频，历史 16:9 素材按 9:16 居中裁切；AI 跟练预览区间由平台内容系统维护。签到入口固定连接本轮需新制作的舒缓热身 AI 跟练内容，以上内容均不在客户管理后台配置。
- 图片屏保默认使用 `assets/screensaver-fun-ai.jpg` 的 1440×2560 海报，按 9:16 铺满设备；后台上传图片后使用所选图片，恢复默认图片后重新展示该海报。
- 身份、人脸、微信、注册和运动成绩均为模拟；不请求摄像头、不调用登录服务。进入站位即自动模拟人脸确认，右侧控件可切换识别结果；此环节不选择登录方式。
- 运动记录保存在当前浏览器 localStorage。客户屏保配置及新用户注册状态仅在当前页面会话有效；刷新会恢复默认配置。支持清除模拟数据。
- 提前结束按实际计时 **达到 10 秒（含）** 即计为有效运动并完成当日签到；正常结束始终计入。
- 里程碑档位已按累计成长节奏确认：运动天数 1/3/7/14/30/60/100/180/365，运动分钟 10/30/60/150/300/600/1500/3000/6000，消耗千卡 50/100/300/500/1000/2000/5000/10000/20000。分钟以常用运动指南的 150/300 分钟周目标为锚点；天数和千卡用于产品激励，不作为健康处方。
- 任意非运动页面 60 秒无操作进入屏保并清理个人身份；退出屏保统一从首页开始，不恢复超时前页面。正在进行的运动不因无操作计时中断；小程序不套用公共设备待机规则。
- 未实现真实算法、后台接口、生产素材发布、离线同步和多设备结算。弱网／断网时本地采集人脸、保存运动会话并在联网后自动补传，已作为技术需求写入评审稿，本 Demo 仅展示需求说明。演示图表、热量与评分不用于效果评价。
- 9:16 画布仅验证浏览器布局，43 寸设备触达、反光、音量与实际交互需现场复核。
- 为方便需求评审，既有功能在相关页面覆盖 40% 黑色遮罩，本轮新增或调整的入口与卡片保持正常亮度；该遮罩仅用于评审，不属于正式产品界面。
- 原型体验按交互大屏 8 页、管理后台 2 页、小程序 1 页罗列页面和本页变动数量，并只展示当前页面需要的模拟控件；切换页面时不相关的用户、身份和时间控制自动隐藏。
- 交互大屏另增加 D08 人群内容页演示。成人和儿童状态均直接使用产品原图；儿童页可点击“趣味锻炼”的“更多”进入内容页并返回。游戏卡片本身不包含交互。

## 最近验证记录（2026-09-24）

规则脚本覆盖运动完成边界、重复结算、运动天数、身份隔离、预览片段和内容池顺序。客户后台原型覆盖屏保类型、人群推荐、指定内容池、排序、图片上传及保存；平台内容参数与设备实机仍需在研发环境验证。

首页已恢复 v1.0 原图，仅以虚线框标注签到入口（用户头像左侧），点击可体验热身签到。签到入口只属于设备首页，不出现在热力健将、跃动少年、康乐银发等人群内容页。体态检测等既有模块仅呈现原图，不接入功能；人群卡片连接本轮选运动演示。

## 我的数据与奖牌

左侧目录可进入“大屏我的数据”或“小程序我的数据”。首页原图的头像也可进入大屏数据页。累计运动卡片右上角奖牌进入两端复用的 D07 个人里程碑页，依次展示运动分钟、消耗千卡和运动天数的当前奖牌及最近两个目标。两端使用当前模拟账号同一份运动记录，无记录时为零；已有数据时，进度条按“当前累计值 ÷ 下一目标值”展示从 0 开始的整体进度，达到档位后保留此前累计，不重新归零；刚好达到档位时显示已点亮并指向下一目标。可先完成运动再查看。跑步、休闲分类和真实二维码未接入。
