# v1.1 功能埋点清单（待研发对齐）

本表仅列本期 20 个 P0 事件。待开发事件与共用事件的后续扩展已迁至[需求池埋点](../backlog/event-tracking.md)。保留原序号与 eventID，不因范围迁移改写历史事件标识。

如事件已有埋点，则忽略，不重复新增。首页、既有列表与筛选等继续沿用已有事件；普通运动的准备、身份、开始与结算复用已有事件，游戏本体不重复上报。

B02 仅按当前组织是否购买心率设备控制入口，不新增用户行为事件；原无数据说明曝光事件已取消。D03 默认配置、封面制作与飞书链接不新增点击事件。

## 统一口径

- 事件附端标识、应用版本、事件时间及脱敏会话标识；不上传姓名、手机号、人脸图像或特征等个人信息。
- 内容使用正式 course_id／game_id；页面文案或 Demo 键不能代替生产 ID。
- 双人分别记录各自身份与运动结算；同一参与者的同一次运动记录重复提交不重复累计，不能漏掉第二人。
- 点击／浏览与服务端结算结果分别统计。离线记录在服务端确认前为待同步，补传成功不重复结算。
- 评审工具的推进时间、视频失败与空池控制不发送生产埋点。已有同义事件优先沿用，不同时上报两套事件。
- 后台配置以保存回执为准；系统默认与自定义沿用 recommended／fixed 属性，三类内容与播放顺序保持一致。
